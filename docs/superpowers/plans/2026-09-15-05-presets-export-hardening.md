# Neural Brush Presets, Export & V1 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish V1 with safe deterministic Brain Presets, private sharing, image/video export, responsive behavior, scientific disclosure, error recovery, final E2E coverage, and production GitHub Pages verification.

**Architecture:** Presets serialize only modulation/brush/version/seed state and are validated against the currently loaded immutable circuit before application. Image export reads the edited render target, while process recording captures the visible Canvas renderer when supported. Hardening adds explicit size/resource limits, worker recovery, responsive controls, final science/privacy UI, and deployment smoke tests.

**Tech Stack:** TypeScript, browser URL fragments, Web APIs (`Blob`, `MediaRecorder`, `captureStream`), Vitest, Playwright, GitHub Actions/Pages

**Spec:** `docs/superpowers/specs/2026-09-15-neural-brush-design.md`

## Global Constraints

- Shared presets contain **no user photo**.
- Preset dataset must be exactly `male-cns:v1.0`; V1 circuit must be exactly `dna-steering-v1`.
- Connection gain remains bounded to **0.0x–2.0x**; stimulation/inhibition remain `0..1`.
- Invalid/untrusted preset data is validated before it touches live state.
- Static GitHub Pages remains fully usable with no backend, no account, no cloud photo storage, and no secret API key.
- PNG export is required; JPEG is supported where appropriate; WebM process recording is best-effort.
- The source photo must not be silently uploaded or embedded in share links.
- Scientific/About copy must distinguish MaleCNS-derived source facts, simplified neural dynamics, synthetic sensory input, optional AI modulation, and artistic brush effects.

### Task 2: Implement deterministic preset file and URL-fragment codec

**Files:**
- Create: `src/preset/PresetCodec.ts`
- Create: `src/preset/PresetFileIO.ts`
- Create: `tests/unit/PresetCodec.test.ts`
- Create: `tests/unit/PresetFileIO.test.ts`

**Interfaces:**
- `PresetCodec.encode(preset): string` returns base64url-encoded canonical UTF-8 JSON without padding.
- `PresetCodec.decode(encoded): unknown` decodes only; validation remains separate.
- Canonical object key order: top-level fixed order, modulation sorted by numeric body ID, gains sorted by numeric source then target.
- Maximum decoded URL JSON: `16 * 1024` bytes.
- `.neuralbrush.json` maximum import: `64 * 1024` bytes.

- [ ] **Step 1: Write failing round-trip/canonicalization tests**

Assert:

- equivalent preset objects with different insertion order encode to identical strings,
- `decode(encode(preset))` deep-equals canonical preset,
- strings over the decoded URL limit are rejected,
- malformed base64url is rejected,
- unicode-free JSON round-trips exactly.

- [ ] **Step 2: Implement canonical JSON construction**

Do not use compressed/decompression libraries in V1. Build a new canonical object, `JSON.stringify`, `TextEncoder`, then base64url encode by converting bytes to binary chunks and replacing `+` -> `-`, `/` -> `_`, and stripping `=`.

Decode reverses the mapping and rejects non `[A-Za-z0-9_-]` characters.

- [ ] **Step 3: Implement URL-fragment helpers**

```ts
export function writePresetFragment(encoded: string): void {
  history.replaceState(null, '', `${location.pathname}${location.search}#preset=${encoded}`);
}

export function readPresetFragment(hash = location.hash): string | null { /* exact key parse */ }
```

Do not put the source image, filename, image bytes, or image-derived semantic data into the fragment.

- [ ] **Step 4: Implement `.neuralbrush.json` download/import**

Export MIME `application/json`, filename `neural-brush-preset.neuralbrush.json`. Import reads text only after file size <= 64 KiB, parses JSON, then passes `unknown` to `validatePreset`.
